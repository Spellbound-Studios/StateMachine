# Spellbound.PackageName

PACKAGE_SENTENCE

## Install

Add this line to `Packages/manifest.json`, replacing `<version>` with a release tag:

```
"com.spellboundstudios.packagename": "https://github.com/Spellbound-Studios/PackageName.git?path=/Packages/PackageName#v<version>"
```

The Spellbound window in Core installs it for you.

## Front door

`PackageNameKit` is the entry point to everything this package offers.

The binding rules are the line text at https://github.com/Spellbound-Studios/.github/tree/main/line
